# Fraction to Mixed Number Converter

A lightweight, single-file web application with an interactive numeric keypad that allows users to enter improper fractions and instantly converts them into simplified mixed numbers.

## Features

- **Interactive Numeric Keypad:** Touch-friendly visual interface designed for quick fraction entry.
- **Real-Time Conversion:** Automatically updates the output as you type.
- **Automatic Simplification:** Uses the Greatest Common Divisor (GCD) algorithm to reduce fractions to their simplest form.
- **Edge Case Handling:** Built-in safeguards against double slashes, missing denominators, and division by zero.
- **Zero Dependencies:** Pure HTML, CSS, and vanilla JavaScript—no external frameworks or build tools required.
